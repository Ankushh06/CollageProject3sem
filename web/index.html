System Architecture: DSA + DBMS Combined

1. DSA Foundation (Graph & Dijkstra)

The city road network is represented in memory as an adjacency list graph List<List<Edge>>. Dijkstra's shortest path algorithm runs in O((V + E) log V) using a binary min-heap (PriorityQueue). Multi-stop delivery combines a greedy nearest-neighbor heuristic with Dijkstra legs.

2. Relational DBMS Foundation (SQLite)

The system adheres to 3NF relational normalization:

  • Tables: locations, roads, drivers, vehicles, delivery_trips, trip_stops, road_audit
  • Triggers: trg_roads_insert and trg_roads_update automatically record road changes and closures into road_audit.
  • Views: v_active_roads and v_trip_summary provide high-level abstractions for route queries and reporting.
  • Transactions: saveTrip wraps trip insertion and all associated stops into a single atomic transaction.
