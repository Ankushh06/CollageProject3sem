Oracle Database Configuration

Current Database Status: SQLITE (ACTIVE)
SQLite (delivery.db)

RouteFlow includes the official Oracle JDBC Driver (ojdbc11.jar) and automatically connects to your Oracle Database instance when configured.

Edit db.properties in your project root with your Oracle credentials:

db.mode=AUTO
oracle.host=localhost
oracle.port=1521
oracle.service=FREEPDB1   # or XEPDB1 / XE
oracle.user=SYSTEM
oracle.password=YourPassword
Tip: If Oracle Database is not installed or temporarily offline, RouteFlow seamlessly uses SQLite so your project never crashes during demos!

System Architecture: DSA + DBMS Combined

1. DSA Core (Graph & Dijkstra Algorithm)

The city map is represented in memory as an adjacency list List<List<Edge>>. Dijkstra's shortest path runs in $O((V+E)\log V)$ using a binary min-heap (PriorityQueue). Multi-stop delivery plans optimal TSP customer visits using greedy nearest-neighbor with Dijkstra legs.

2. Dual Relational DBMS (Oracle + SQLite)

The system adheres to 3NF relational database normalization:

  • Tables: locations, roads, drivers, vehicles, delivery_trips, trip_stops, road_audit
  • Automated Triggers: trg_roads_insert and trg_roads_update automatically track road changes and closures.
  • Views: v_active_roads and v_trip_summary provide high-level reporting.
  • Atomic Transactions: Saves trip and all its ordered stops inside an atomic transaction with automatic rollback on failure.
