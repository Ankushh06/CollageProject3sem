System Architecture: Pure C++14 ADS Engine

1. Graph ADS Core & Dijkstra Algorithm

The city map is represented purely in memory as an adjacency list std::vector<std::vector<Edge>>. Dijkstra's shortest path runs in $O((V+E)\log V)$ using a binary min-heap (std::priority_queue). Multi-stop delivery plans optimal TSP customer visits using greedy nearest-neighbor with Dijkstra legs.

2. Dynamic In-Memory Graph Operations

The pure C++ engine provides dynamic runtime graph manipulation:

  • Dynamic Edge Closures: Instantly simulate road closures and blockages; the adjacency list is re-weighted so Dijkstra computes real-time detours.
  • Dynamic Vertices: Add new delivery locations on the fly with live automatic spatial coordinate calculation.
  • Dual Weight Optimization: Switch instantly between Shortest Distance (km) and Fastest Travel Time (minutes).
  • Native Winsock Web Server: An embedded multithreaded C++ HTTP server delivers static assets and REST API endpoints directly on localhost.
